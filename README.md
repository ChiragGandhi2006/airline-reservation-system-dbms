# ✈️ Airline Reservation System (DBMS Project)

## 📌 Description
A DBMS-based airline reservation system that manages passengers, flights, bookings, and payments.

## ⚙️ Tech Stack
- Python
- MySQL
- CustomTkinter

## 📂 Features
- Flight booking
- Passenger management
- Seat selection
- Payment handling

## 🗂️ Folder Structure
- Testing.py → Main file
- Database.sql → Database schema
- my_tickets/ → Ticket data
